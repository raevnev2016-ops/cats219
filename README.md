# КОТОХВАТ — Black Friday / Стадикэтс

Мобильная браузерная аркада для Telegram. Независимая интерпретация классической механики claw machine. Использует предоставленные маскоты школы, без внешних библиотек, аккаунтов и сервера.

## Как играть
1. Выбрать «История» или «Общество».
2. Клешня движется слева направо. В нужный момент нажать **«ХВАТЬ!»** или коснуться игрового поля.
3. За 3 попытки набрать 250 игровых очков. Захваты могут быть пустыми. Разные подарки приносят разное число очков, коробка «?» содержит случайный игровой бонус.
4. После трёх попыток открывается итоговый экран с результатом и условиями акции. Скидка доступна вне зависимости от победы.

## Публикация на GitHub Pages
1. Распакуйте ZIP. Загрузите `index.html`, `style.css`, `game.js`, всю папку `assets` в **корень публичного репозитория** GitHub.
2. В Settings → Pages выберите `Deploy from a branch`, ветку `main`, папку `/(root)`.
3. После публикации проверьте ссылку в Telegram на Android и iPhone (особенно высоту интерфейса, кнопки и переход на сайт курса).
